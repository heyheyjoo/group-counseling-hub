# group-counseling-hub (집단상담 허브)

> **오프라인 현장 연계형 디지털 집단상담 플랫폼**  
> 한국 상담 현장의 디지털 도구 부족 문제를 해결하고, 오프라인 집단상담의 온기를 디지털 실시간 상호작용으로 연결합니다.

---

## 🌟 기획 배경

현재 한국의 상담 및 교육 현장에서는 다양한 집단상담(심리 안정 프로그램, 학교폭력 예방 교육, 감정 조절 훈련 등)이 활발하게 진행되고 있으나, 이를 보조해 줄 **디지털 상호작용 도구**는 극히 부족한 실정입니다. 
- 대다수 상담자가 아날로그 포스트잇, 화이트보드, 인쇄물에만 의존하고 있어 자료 수집과 보관이 어렵습니다.
- 학생들의 고민을 실시간으로 수집하고 분석하여 정형화된 치료 기법(DBT, CBT 등)과 신속하게 매칭하는 도구가 부재합니다.
- 이에 따라 **'group-counseling-hub'**는 학교 교실이나 상담 센터 등 **오프라인 현장에서 교사와 학생이 실시간으로 소통하고 호흡을 나누며 활동을 기록**할 수 있는 백엔드리스(Backendless) 디지털 보조 솔루션으로 개발되었습니다.

---

## 🛠️ 기술 스택

외부 패키지 의존성을 최소화하여 시스템 가벼움과 보안성을 극대화한 **백엔드리스 아키텍처**입니다.
- **Core**: React 18, TypeScript, Vite
- **State & Synchrony**:
  - **BroadcastChannel API**: 단일 PC 내 탭/윈도우 간 실시간 상태 동기화 및 스티커 수신 이벤트 전송 (별도 백엔드 서버 없이 동작).
  - **LocalStorage**: 단계(Step), 고민 목록, 선택 이론, 세션 로그 기록의 영구적 보존 및 브라우저 새로고침 대응.
- **Styling**: Vanilla CSS Variables, Google Fonts (`Noto Sans KR` 400/500/700)
- **Zero External Dependencies**: `react-router-dom`, `TailwindCSS` 등 외부 라이브러리를 일절 사용하지 않는 초경량 순수 코드베이스.

## 💻 시연 방법 (Quick Start)

본 프로젝트는 한 대의 PC 브라우저 환경에서 선생님 탭과 학생 탭을 동시에 띄워 실시간으로 시연하도록 구성되어 있습니다.

### 1. 의존성 설치 및 로컬 서버 실행
```bash
# 의존성 패키지 설치
npm install

# 로컬 개발 서버 시작
npm run dev
```

### 2. 브라우저 탭 2개 열기
- 브라우저를 열고 개발 서버 주소(예: `http://localhost:5173`)로 **2개의 탭** 또는 **좌우 분할 윈도우**를 띄웁니다.
- **Tab A**: **[선생님 모드]**를 선택합니다.
- **Tab B**: **[학생 모드]**를 선택합니다.

### 3. 단계별 시연 시나리오
1. **1단계 [고민 수집]**:
   - **학생(Tab B)**이 감정 이모지와 고민을 적고 '익명으로 고민 올리기'를 클릭합니다.
   - **선생님(Tab A)** 화면에 해당 고민 포스트잇 카드가 실시간으로 팝업됩니다.
   - 선생님 화면의 `시연용 더미 데이터 5개 채우기` 버튼을 눌러 빠른 분석 준비 상태를 만들 수 있습니다.
   - 5개 이상의 고민이 모이면 `AI 분석 및 상담 이론 추천` 버튼이 활성화됩니다.
2. **2단계 [AI 이론 추천]**:
   - 선생님이 분석 버튼을 누르면 3초간 AI 고민 키워드 분석 애니메이션이 작동합니다.
   - 매칭률 94%의 **DBT (변증법적 행동치료)** 추천 카드가 나타납니다.
   - 학생 탭은 선생님이 선택할 때까지 대기 화면으로 동기화됩니다.
   - 선생님이 DBT 카드를 클릭하면 양쪽 탭이 동시에 3단계로 전환됩니다.
3. **3단계 [라이브 세션]**:
   - **학생(Tab B)** 화면에 60초(6사이클) 동안 작동하는 **TippTimer** 호흡 원이 생성됩니다.
     - 4초 들이쉬기 (원 확장: 120px ➔ 200px)
     - 6초 내쉬기 (원 수축: 200px ➔ 120px)
   - **선생님(Tab A)** 화면 좌측에는 DBT TIPP 기법 상담 가이드라인이 제시되며, 우측에는 실시간 타이머가 작동합니다.
   - 학생이 호흡 완료 후 5가지 응원 스티커(`💚`, `🌿`, `✨`, `🌸`, `☁️`)를 클릭하면 선생님 화면에 실시간으로 스티커가 팝업 애니메이션과 함께 적재됩니다.
4. **4단계 [기록실]**:
   - 선생님이 `세션 종료`를 누르면 두 탭 모두 기록실로 이동합니다.
   - 방금 진행한 세션이 LocalStorage에 자동 저장되어 리스트 카드로 출력됩니다.
   - `기록 내보내기`를 눌러 세션 로그 데이터를 JSON 파일로 즉시 다운로드할 수 있습니다.
   - `새 세션 시작하기`를 누르면 기존 고민/스티커/이론 상태를 초기화하고 1단계로 순환하여 돌아갑니다.

## 🎨 디자인 가이드라인 (Design System)

심리적 안정감을 주는 부드럽고 따뜻한 톤앤매너로 구성되어 있습니다.
- **배경**: 따뜻한 아이보리 (`#FDFAF5`)
- **포인트/강조**: 파스텔 민트 (`#A8D5C2`, `#81B8A1`)
- **상호작용 버튼**: 따뜻한 피치 (`#F4C2A1`, `#E0A481`)
- **텍스트/아이콘**: 소프트 챠콜 그레이 (`#4A4A4A`)
- **카드/포스트잇**: 깔끔한 화이트 (`#FFFFFF`)
